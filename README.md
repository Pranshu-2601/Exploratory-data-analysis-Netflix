# 📊 Netflix_Titles EDA
Exploratory Data Analysis (EDA) on the [Netflix Titles dataset](https://www.kaggle.com/datasets/shivamb/netflix-shows), focusing on uncovering trends, patterns, and insights from content available on Netflix.

---

## 📁 Dataset
- **Source**: Kaggle
- **File**: `netflix_titles.csv`
- **Fields**: Title, Director, Cast, Country, Date Added, Release Year, Rating, Duration, Genre, etc.

---

## 📌 Objectives
- Understand Netflix's content composition
- Identify trends over time (release years, additions to Netflix)
- Analyze genre, ratings, and content duration
- Extract insights on cast, directors, and countries
- Visualize key metrics and build intuitive charts

---

## 📒 Contents of the Notebook
- **Data Cleaning**: Handle missing values, convert dates, and feature engineering
- **Univariate Analysis**: Distributions of content types, ratings, durations
- **Time Series Trends**: Content added per year/month
- **Genre & Country Breakdown**: Popular genres and countries producing content
- **Top Cast & Directors**
- **Text Analysis**: Word clouds from titles and descriptions
- **Interactive Visuals**: Using Plotly for engaging exploration

---

